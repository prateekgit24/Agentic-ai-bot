TASK 6: Permissions System
──────────────────────────────────────────────
Goal: per-user toggles for which tools they can use, stored in DB, 
      enforced server-side before tool execution.

Step 1 — DB Schema (node-server/models/User.js):
  Add to UserSchema:
    permissions: {
      canWebSearch:   { type: Boolean, default: true },
      canRunCode:     { type: Boolean, default: true },
      canCreateFiles: { type: Boolean, default: true },
      canSetAlarms:   { type: Boolean, default: true },
      canPlayMusic:   { type: Boolean, default: true },
      canGetNews:     { type: Boolean, default: true },
    }

Step 2 — Server enforcement (node-server/server.js, in /chat endpoint):
  After parsing tool JSON, before calling toolFunction:
    const permMap = {
      web_search: "canWebSearch", run_code: "canRunCode",
      file_manager: "canCreateFiles", alarm: "canSetAlarms",
      get_news: "canGetNews"
    };
    const requiredPerm = permMap[parsed.tool];
    if (requiredPerm && req.user && req.user.permissions) {
      if (!req.user.permissions[requiredPerm]) {
        return res.json({ type:"tool_result", tool:parsed.tool, ui:null,
          error:"Tool disabled by your permissions." });
      }
    }
  Apply same check in /chat/stream endpoint.

Step 3 — API route (node-server/server.js or routes/profile.js):
  PATCH /api/profile/permissions
    body: { canWebSearch: bool, canRunCode: bool, ... }
    req.user.permissions = { ...req.user.permissions, ...req.body }
    await req.user.save()
    res.json({ ok: true })

Step 4 — Frontend UI (index.html + script.js):
  Add "Permissions" settings panel in sidebar (there's already a Permissions
  button — check index.html for id="panel-permissions" or similar).
  Panel has toggle rows for each permission.
  On change: fetch PATCH /api/profile/permissions with updated values.
  On settings open: fetch GET /api/profile to load current permissions,
    populate toggles.
